# GeraStore

**Русский каталог IPA-приложений для GBox**

Автор: **Гера Кухтов (ГЕРЫЧ)**

GeraStore — это открытый источник приложений для [GBox](https://gbox.run). Здесь собраны полезные и популярные IPA, которые можно устанавливать через GBox с самоподписью (SELF_SIGN).

## Как добавить источник в GBox

1. Откройте **GBox**
2. Перейдите в раздел **Источники** (Sources)
3. Нажмите **+** / **Добавить источник**
4. Вставьте ссылку:

```
https://gkuhtov.github.io/GeraStore/repo.json
```

или

```
https://raw.githubusercontent.com/gkuhtov/GeraStore/main/repo.json
```

5. Подтвердите добавление

После этого все приложения из GeraStore появятся в вашем GBox.

## Особенности

- Полностью русский интерфейс и описания
- Удобные категории
- Регулярные обновления
- IPA хранятся в GitHub Releases (быстро и надёжно)
- Открытый исходный код

## Структура репозитория

```
GeraStore/
├── repo.json          # Основной файл источника для GBox
├── index.html         # Страница-лендинг
├── icons/             # Иконки приложений
├── apps/              # Исходные данные (если используются)
└── generator.py       # Скрипт генерации 
```


## Предупреждение

- Все приложения требуют **самоподписи** (SELF_SIGN).
- Использование неофициальных IPA может нарушать условия использования App Store и нести риски (бан аккаунта, malware и т.д.).
- Автор не несёт ответственности за возможные последствия.
- Используйте на свой страх и риск.
